# Схема процесса автоматического переобучения ML-модели

## 1. Схема процесса (Диаграмма)

Ниже представлена схема автоматического пайплайна переобучения модели (Continuous Training). Схема иллюстрирует путь от момента, когда модель начала устаревать, до безопасного внедрения новой версии.

```mermaid
graph TD
    A[Триггер: Падение ROC-AUC ниже 0.80<br>или по расписанию] --> B(Получение новых данных из CRM)
    B --> C(Препроцессинг: очистка, кодирование)
    C --> D(Обучение новой версии модели Random Forest)
    D --> E(Валидация: расчет метрик на Test-выборке)

    E --> F{Проверка качества:<br>ROC-AUC > 0.80 И<br>ROC-AUC_new > ROC-AUC_old?}

    F -->|Да, модель лучше| G(Регистрация модели: сохранение артефактов)
    G --> H(Деплой: замена модели в Production)
    H --> I(Мониторинг новой модели)

    F -->|Нет, модель хуже| J(Сохранение старой модели)
    J --> K(Алерт команде Data Science: требуется ручной анализ)
